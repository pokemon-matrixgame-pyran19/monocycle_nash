# ドキュメント

現在のドキュメント配置と運用方針をまとめます。
READMEの補助資料は `readme/`、進行中の作業メモは `working/` で管理します。

## 構成

- `readme/`: READMEの補助ドキュメント
- `working/`: 現在進行中の作業メモ
- `class_design/`: 旧仕様を含む設計資料アーカイブ
- `theory/`: 理論背景
- `test/`: テスト設計メモ
- `test_strategy.md`: 全体のテスト戦略
- `experiment/`: 実験計画・実験レポート（時点依存の記録）

## 運用方針

- READMEの補助文書は `readme/` に置く
- これから実装・更新する内容は `working/` に記載する
- 旧仕様として保存する文書は `class_design/` にアーカイブする
- `class_design/` 配下は明示的にアーカイブであり、現行実装との差分があってよい
