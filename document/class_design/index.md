# class_design

このフォルダは、実装前〜実装中に作成した設計資料のアーカイブ。
最新の実装対象に関する仕様は document/working を参照。

## サブフォルダ

- initial_design: 初期設計の分割ドキュメント群
- input_loader: 入力読み込み設計とユースケース別エントリーポイント案
- management: run結果管理と runmeta CLI の仕様
- clean_refactering: 依存関係を見直すリファクタリングメモ

## 補足

- 各サブフォルダの index.md に、ファイルごとの概要を記載する
- ここにある文書は設計経緯を含むため、現行実装と差分がある場合がある
