# initial_design

初期設計時点の仕様を章ごとに分割したアーカイブ。

## ファイル一覧

- preamble.md: 前提、設計方針、ディレクトリ構成の整理
- modeling.md: 概念モデリング
- components.md: モジュール/クラス構成と責務
- pure_strategy.md: 純粋戦略を中心にした設計整理
- team_payoff.md: チーム利得行列計算の設計
- merits.md: 設計方針のメリット整理
- infra_output.md: 出力/永続化寄りの設計メモ
- usecase.md: 想定ユースケース
- todo.txt: 当時の作業メモ

## 補足

- このフォルダの内容は初期設計時点の記録であり、現行実装との差分がありうる
