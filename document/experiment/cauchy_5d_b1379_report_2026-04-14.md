# コーシー型行列 5次元 均衡解 vs 積公式 比較レポート（2026-04-14）

## 目的

`compare_product_formula` ユースケースを使い、以下のパラメータの5次元コーシー型行列に対して

1. 数値的均衡解（nashpy 線形計画法による厳密均衡）
2. 積公式 $v_i = \prod_{j \neq i}(b_i - b_j)$ から形式的に得られる「擬似均衡」

を比較し、積公式の有効性を検証する。

---

## 入力パラメータ

| パラメータ | 値 |
|---|---|
| 次元 | 5 |
| $a$ | [1, 1, 1, 1, 1]（全成分の絶対値 = 1） |
| $b$ | [1, 3, 4, 7, 9] |
| ラベル | s1, s2, s3, s4, s5 |

行列の定義：

$$B_{ij} = \frac{a_i \cdot a_j}{b_i - b_j} = \frac{1}{b_i - b_j} \quad (i \neq j), \quad B_{ii} = 0$$

## 考察

### 純粋戦略均衡の検証

nashpy が返した純粋戦略 (s5, s5) が Nash 均衡であることを手計算で確認する。

列プレイヤーが s5（$b=9$）を選んだとき、行プレイヤーの各戦略に対する利得は：

$$B_{i,5} = \frac{1}{b_i - 9}$$

| 戦略 | $b_i$ | $B_{i,5}$ |
|---|---|---|
| s1 | 1 | $1/(1-9) = -0.125$ |
| s2 | 3 | $1/(3-9) \approx -0.167$ |
| s3 | 4 | $1/(4-9) = -0.200$ |
| s4 | 7 | $1/(7-9) = -0.500$ |
| s5 | 9 | $0$ |

**行プレイヤーの最適反応は s5**（利得 0 が最大）。  
交代行列の対称性から列プレイヤーの最適反応も s5 であり、**(s5, s5) は純粋 Nash 均衡**。  
残差ベクトル $Bx^* = [-0.125, -0.167, -0.200, -0.500, 0]$、最大残差 = 0.5 は JSON 出力と一致。

### 積公式の失敗原因

積公式が有効になる条件は「$b$ の大小関係が交代的な a 符号パターンと整合する場合」に限られる。
$b = [1, 3, 4, 7, 9]$ では $b$ が単調増加であり、偶数番目の $v_i$ が必ず負になる：

$$v_i = \prod_{j \neq i}(b_i - b_j)$$

$b$ が昇順に並んだ $n=5$ 次元では、$v_2$ と $v_4$ が負になる（$b_2, b_4$ の両側に奇数個の項が残るため符号が逆）。

$a_i = 1$ の場合、$a_i$ での除算は符号を変えないため、積公式は依然として負成分を持ち、  
**確率分布として正規化できない**（`is_valid = false`）。

テストコードが採用している交代符号パターン $a = [1,-1,1,-1,1]$ はこれを補正するために設計されており、  
$v_i / a_i$ が全て正になるよう符号を調整している。本パラメータ ($a=[1,1,1,1,1]$) では  
その補正がかかっておらず、積公式は機能しない。

## まとめ

| 比較項目 | 値 |
|---|---|
| 数値均衡（nashpy） | 純粋戦略 s5 = 1.0 |
| 積公式 $v_i$（生値） | [288, -48, 45, -144, 480]（負成分あり） |
| 積公式 → 確率化 | **不可（is_valid = false）** |
| 均衡残差（数値解） | 0.5（純粋戦略均衡であることと整合） |

$a$ の絶対値をすべて 1、$b=[1,3,4,7,9]$ とした場合、このゲームは**純粋戦略 (s5, s5) が Nash 均衡**として存在し、  
積公式による均衡推定は無効である。積公式が成立するには $a_i$ の符号を適切に設定し、$v_i / a_i$ の全成分が正になるよう調整する必要がある。
